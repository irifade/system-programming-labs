# Задание 3-4: Диагностика сетевых соединений

В данном задании проведена диагностика локального TCP-сервера (из задания 3-3), запущенного на порту 8080 (Вариант 4).

## Основные наблюдения
1. **Утилита nc (netcat)** успешно подключилась к localhost:8080. При отправке строки 'Привет, сервер!' был получен мгновенный эхо-ответ от программы.
2. **Утилита ss** показала, что порт 8080 находится в состоянии LISTEN (ожидание соединений) и закреплен за процессом 	ask.
3. **Утилита lsof** подтвердила, что сетевой сокет IPv4 удерживается конкретным PID процесса нашего эхо-сервера.
4. **Утилита ping** показала минимальную задержку (микросекунды) при обращении к петлевому интерфейсу (localhost), потерь пакетов нет.

Полный лог терминала сохранен в файле commands.txt.

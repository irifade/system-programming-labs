# Практика 3. Задание 3-1: Неименованные каналы pipe()

Программа демонстрирует взаимодействие родительского и дочернего процессов через два неименованных канала (Вариант 4).

## Описание работы
1. **Родитель** генерирует 20 случайных чисел и отправляет их потомку через `pipe1`.
2. **Дочерний процесс** считывает числа, находит максимальное значение и возвращает его родителю через `pipe2`.

## Сборка и запуск
```bash
gcc -Wall -Wextra -o task task.c
./task
```

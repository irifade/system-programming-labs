# Практика 4. Задание 4-4: Анализ памяти и процессов

Проведение динамического анализа распределения памяти процесса и верификация кода на отсутствие утечек (Вариант 4).

## Основные выводы по анализу
1. **Утилита Valgrind (Memcheck)** успешно проанализировала работу динамического выделения памяти для матрицы 5x5.
2. В секции `HEAP SUMMARY` указано: `in use at exit: 0 bytes in 0 blocks`. Это подтверждает, что программа полностью освобождает все ресурсы перед завершением работы.
3. Итоговый вердикт утилиты: `All heap blocks were freed -- no leaks are possible` (утечки памяти отсутствуют, ошибок работы с указателями `ERROR SUMMARY: 0` не обнаружено).
4. Анализ `/proc/[PID]/maps` показывает стандартную разметку виртуального адресного пространства процесса, включая сегменты кода (r-xp), данных (r--p/rw-p) и системный стек.

Полный лог работы профилировщика сохранен в файле `analysis.txt`.

# Практика 4. Задание 4-3: Демоны и фоновые процессы

Реализация полноценного системного демона, который в фоновом режиме отслеживает состояние директории (Вариант 4).

## Описание работы
1. Программа делает первый `fork()`, отпуская терминал, и создает новую сессию через `setsid()`.
2. Изменяется рабочая директория (`chdir("/")`) и сбрасывается файловая маска (`umask(0)`).
3. Закрываются стандартные дескрипторы потоков (`stdin`, `stdout`, `stderr`), изолируя процесс от терминала.
4. Каждые 15 секунд демон производит подсчет количества файлов в директории `/tmp` и сохраняет отчет с временной меткой в лог-файл `/tmp/daemon_task.log`.
5. Реализован перехват сигнала `SIGTERM` для корректной записи о завершении работы в лог.

## Сборка и запуск
```bash
gcc -Wall -Wextra -o task task.c
./task
```

## Управление процессом демона
Посмотреть, что демон работает в фоне:
```bash
ps aux | grep ./task
```
Посмотреть лог работы демона:
```bash
tail -f /tmp/daemon_task.log
```
Остановить демона:
```bash
pkill -15 task
```

## Структура репозитория

### Практика 1: Системные вызовы, процессы, файлы

*   1-1: Системные вызовы (open/read/write/close)
*   1-2: Процессы fork/exec
*   1-3: Файловая система и права (bash скрипты)
*   1-4: Диагностика процессов (ps, top, /proc)

### Практика 2: Потоки, синхронизация, сигналы

*   2-1: Многопоточность (pthread)
*   2-2: Синхронизация с мьютексами
*   2-3: Обработка сигналов (signal/sigaction)
*   2-4: Отладка с strace

### Практика 3: Каналы, сокеты, взаимодействие процессов
*   3-1: Передача данных между процессами через неименованные каналы `pipe()`. Поиск максимума.
*   3-2: Двусторонний мини-чат между терминалами через именованный канал FIFO.
*   3-3: Сетевое взаимодействие процессов через TCP-сокеты (Эхо-сервер и клиент).
*   3-4: Диагностика сетевых соединений утилитами `ss`, `lsof`, `ping`, `nc`.

### Практика 4: Управление памятью и фоновые процессы
*   4-1: Динамическая память (`malloc`, `free`). Выделение под матрицу 5×5 и вывод главной диагонали.
*   4-2: Отображение файлов в память. Быстрое копирование файлов через `mmap()`.
*   4-3: Системные демоны. Фоновый процесс подсчета файлов в директории каждые 15 секунд.
*   4-4: Динамический анализ памяти и процессов. Проверка кода на утечки с помощью `valgrind`.
